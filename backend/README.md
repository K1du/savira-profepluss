# Backend ProfePluss

Este directorio contendrá todo el código del backend del proyecto, desarrollado con Django y Django REST Framework.

## Estructura inicial sugerida
- `manage.py`: Script principal de Django.
- `profepluss/`: Configuración principal del proyecto Django.
- `apps/`: Aquí se ubicarán las aplicaciones principales (usuarios, documentos, flashcards, chatbot, etc.).
- `requirements.txt`: Dependencias de Python necesarias para el backend.

## Primeros pasos sugeridos
1. Crear entorno virtual Python
2. Instalar Django y Django REST Framework
3. Crear el proyecto base y las primeras apps (usuarios, documentos)
4. Configurar base de datos SQLite para desarrollo local
5. Preparar endpoints REST básicos
6. Documentar endpoints y estructura

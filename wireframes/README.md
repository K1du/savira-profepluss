# Wireframes ProfePluss

Esta carpeta contiene los wireframes (esquemas visuales) de las pantallas principales de la plataforma ProfePluss.

## ¿Qué es un wireframe?
Un wireframe es un dibujo o esquema simple de una pantalla. Muestra la estructura, los elementos principales y el flujo de usuario, sin detalles de diseño ni colores. Sirve para que todos los departamentos entiendan cómo será la app antes de programar nada.

## Pantallas incluidas
- Login/Registro
- Onboarding
- Panel de usuario
- Subida de documentos
- Visualización de documentos y flashcards
- Chatbot educativo
- Gestión de grupos y chat
- Configuración/perfil
- Navegación principal

Cada imagen tiene una breve explicación para que cualquier persona (con o sin experiencia) entienda su función.

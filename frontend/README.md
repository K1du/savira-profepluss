# Frontend ProfePluss

Este directorio contendrá todo el código del frontend del proyecto, desarrollado con React y Tailwind CSS.

## Estructura inicial sugerida
- `src/`: Código fuente principal
  - `components/`: Componentes reutilizables (Navbar, Sidebar, Upload, etc.)
  - `pages/`: Vistas principales (Login, Panel, Chatbot, etc.)
  - `i18n/`: Archivos de internacionalización (traducciones)
- `public/`: Archivos estáticos y recursos
- `package.json`: Dependencias y scripts de React

## Primeros pasos sugeridos
1. Inicializar el proyecto con Create React App, Vite o similar
2. Instalar Tailwind CSS e i18next para internacionalización
3. Crear los primeros componentes y páginas básicas
4. Configurar el sistema de rutas y navegación
5. Documentar la estructura y los estilos

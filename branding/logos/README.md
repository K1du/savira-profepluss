# Carpeta de Logos Savira

Aquí encontrarás todas las variantes del logotipo de Savira en formatos SVG y PNG, listos para web, impresión y recursos corporativos. Cada logo tiene su versión principal, monocromo y favicon.

- **logo_savira_main.svg/png**: Logo principal a color
- **logo_savira_mono.svg/png**: Logo monocromo
- **logo_savira_icon.svg/png**: Solo isotipo/icono
- **favicon_savira.svg/png/ico**: Favicon para web

---

Todos los logos han sido diseñados para mantener la identidad visual profesional y sencilla de Savira. Puedes usarlos libremente en la web, documentos, presentaciones y material corporativo.

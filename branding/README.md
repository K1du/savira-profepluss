# Branding y Recursos Corporativos – Savira

Esta carpeta contiene todos los recursos, guías y plantillas necesarios para la gestión de la imagen de marca, marketing y diseño corporativo de Savira.

## Estructura

- `/BRAND_LIST_1.md`, `/BRAND_LIST_2.md`, `/BRAND_LIST_3.md`: 700+ nombres de marca originales y explicados.
- `/SAVIRA_BRAND_BOOK.md`: Brand book completo de Savira.
- `/MARKETING_PLAN.md`: Plan de marketing integral.
- `/CORPORATE_DESIGN_GUIDE.md`: Guía de diseño corporativo (colores, tipografía, papelería, banners, etc).
- `/logos/`: Versiones SVG y PNG del logo (añadir aquí los archivos gráficos).
- `/plantillas/`: Plantillas de folio, tarjeta, firma email, presentaciones.
- `/banners/`: Ejemplos para redes sociales.
- `/mockups/`: Ejemplos visuales y recursos para presentaciones.

## Uso

1. Consulta el Brand Book y la guía de diseño antes de crear cualquier recurso visual.
2. Utiliza las plantillas para mantener coherencia visual y profesionalidad.
3. Adapta los ejemplos de posts y banners para redes sociales y campañas.
4. Sigue el plan de marketing para acciones de captación y posicionamiento.
